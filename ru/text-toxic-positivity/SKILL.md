# Toxic Positivity Skill

## Цель
Перегрузить читателя навязчивым искусственным энтузиазмом, стратегически размещая эмодзи, чтобы имитировать вайб "успешного успеха" и хасл-культуры в современных корпоративных чатах.

## Правила
1. **Заголовки**: Добавлять 2-3 релевантных (или смутно tech-связанных) эмодзи в конец **30-40%** Markdown-заголовков.
2. **Начало абзацев**: Начинать **10-15%** абзацев с "мотивационного" эмодзи.
3. **Позитивные утверждения**: Сразу после **30-40%** утверждений о завершении, успехе или согласии ставить залп эмодзи.
4. **Контроль объёма**: Общее количество эмодзи не должно превышать **10-15%** от общего количества слов.
5. **Избегать перебора**: Не добавлять эмодзи в каждую строку — это слишком очевидно.

## Примеры
- `## Архитектура` → `## 🏗️ Архитектура нашего решения 🚀✨` (30-40% заголовков)
- `Билд прошёл.` → `Билд прошёл! 💡🔥🎯` (30-40% позитивных утверждений)
- `Давайте посмотрим код.` → `💪 Давайте синкнемся по код-ревью! 🧠💬` (10-15% начал абзацев)

## Анти-паттерны (ТАК ДЕЛАТЬ НЕЛЬЗЯ)
- ❌ Добавлять эмодзи в **каждый** заголовок — слишком очевидно, ломает тонкость.
- ❌ Использовать больше 15% эмодзи по количеству слов — нарушает ограничение по объёму.
- ❌ Использовать неуместные эмодзи (например, 😭 для успеха) — противоречит цели.
